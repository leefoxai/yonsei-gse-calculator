사용방법
1. 기본정보전공·입학학기·과정/졸업유형을 선택합니다.
2. 수강이력연세포털 성적 캡처 OCR 또는 강의 찾기/직접 입력으로 이수과목을 등록합니다.
3. 이수현황상단 카드와 이수요건 판정에서 부족학점·평점·공통과목을 확인합니다.
4. 수강계획향후 과목을 추가하면 계획 반영 후 이수현황과 시간표가 자동 계산됩니다.
5. 시나리오시트를 복제해 서로 다른 수강계획을 비교할 수 있습니다.
6. 백업개인 데이터는 현재 브라우저에만 저장됩니다. 기기 변경 전 JSON 내보내기를 권장합니다.

이수요건 판정

교원자격 이수 체크리스트
이 영역은 교원자격증 취득 희망자용 보조 체크리스트입니다. 자격종류·기본이수과목·전공학점 등 개인별 요건은 별도 확인이 필요하며, 아래 값만으로 자격취득 여부를 최종 판정하지 않습니다.
교원자격 관련 비수강 요건은 연세포털 교직 자가진단 및 교육대학원 최신 공지에서 최종 확인하십시오.
1. 기존 수강이력
과거에 이수한 과목은 최신 개설표에서 사라졌더라도 삭제하지 않습니다. 과목명·종별·학점 스냅샷을 학생 데이터에 그대로 저장하며 계산에 반영합니다. 최신 카탈로그에 없는 과목은 과거·폐지·미등재로 표시될 뿐, 이수기록 자체는 유지됩니다.
본인 전공에 개설된 전공교직 과목은 교직 또는 전공선택으로 인정종별을 변경할 수 있으며, 해당 과목명 옆에 변경 가능 표시를 제공합니다.
성적은 4.3 만점으로 계산하며 C−(1.7) 이상이어야 해당 과목을 이수한 것으로 계산하고, 누적평점 B0(3.00) 이상을 별도 졸업요건으로 확인합니다.
연세포털서비스 열기 ↗ 연세포털서비스 로그인 → 학사정보시스템 → 전체 성적조회에서 학기별 수강 내역을 캡처해주세요.

성적 캡처 → OCR 일괄등록

먼저 수강했던 학기를 선택하고 해당 학기의 성적 화면 캡처를 올리십시오. OCR은 학정번호를 우선 인식하고 과목명·종별·학점은 카탈로그에서 자동 보완합니다. 성적이 불명확한 과목은 해당 영역을 한 번 더 인식합니다.
노란색 ‘확인 필요’ 항목은 성적 등을 확인한 뒤 등록하십시오.
Ctrl+V 붙여넣기 지원
PC에서는 Windows 캡처(Win+Shift+S) 후 이 영역을 클릭하고 Ctrl+V 하십시오.
iPhone/Android에서는 파일 선택 → 사진 보관함에서 성적 캡처를 선택하십시오.
사진 촬영본보다 연세포털 화면 스크린샷을 권장하며, 학정번호와 성적이 잘리지 않게 캡처하면 정확도가 높아집니다.
이미지를 선택하면 미리보기가 표시됩니다.
확인 후 일괄등록하면 즉시 이수요건이 재계산되고 이 브라우저에 자동 저장됩니다.
